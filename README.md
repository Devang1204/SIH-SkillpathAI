# SkillPathAI

An AI-powered platform that analyzes a student's profile and creates a personalized path toward their career goals.

## Problem Statement

Students lack personalized guidance to understand their current skills, identify gaps, and know what to learn for their desired careers.

## Impact & Benefits

SkillPathAI provides personalized, actionable career guidance, helping students focus on the right skills and build a clear roadmap toward their goals.

## Current Features

- CV Upload & AI Analysis
- Target Career Role Selection
- Experience-Based Questions
- Personalized Profile Dashboard
- Skill Profile — skills they already have
- Skills to Learn — identified skill gaps
- Personalized Learning Roadmap

## Future Features

- Career & Job Analyzer — identify prospective jobs based on existing skills
- Skill Assessment — test the student's actual skill level
- Skill Leveling — classify skills as Basic → Intermediate → Advanced
- Adaptive Recommendations — update the roadmap based on assessment results
